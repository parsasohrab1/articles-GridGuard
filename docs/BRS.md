# Business Requirements Specification – GridGuard

| ID | Requirement |
|----|-------------|
| BR-1 | Screen grid-control parameter sets as stable or unstable without solving the characteristic equation each time. |
| BR-2 | Guarantee coverage of the unstable class (the dangerous one) and refer uncertain cases to an analyst. |
| BR-3 | Measure how the guarantee behaves when new parameter sets come from a different region (larger reaction times). |
| BR-4 | State clearly that the data are simulated and that no claim is made about real grids. |

Out of scope: field PMU data, fault classification, real-time deployment.
